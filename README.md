 Sistema Web de Triagem e Agendamento de Escuta Psicológica Comunitária

Aplicação web dinâmica e responsiva desenvolvida como projeto de extensão para estruturar a gestão de agendamentos de acolhimento psicológico.

 Tecnologias Utilizadas
* Python / Flask
* HTML5 Semântico
* CSS3 Responsivo (Flexbox/Grid)
